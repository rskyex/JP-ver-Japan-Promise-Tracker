# Ingestion

このディレクトリは、実データ取り込みのためのスクリプトや設定を格納します。

## 将来追加予定のモジュール

### kokkai-ingestion.ts
- 国会会議録検索APIから発言データを定期取得
- 議員IDと発言の紐づけ
- issueAreaの自動分類（キーワードマッチ or LLMによる分類）

### politician-ingestion.ts
- 衆参両院の議員名鑑から議員マスタを取得・更新
- 当選回数・選挙区・委員会所属の最新化

### manifesto-ingestion.ts
- 各政党のマニフェストページから公約テキストを取得
- テキスト分類パイプラインへの投入

## 2期以上の全議員に拡張するには

1. **politician-ingestion.ts** で衆参議員名鑑APIを接続し、全議員データを取得
2. `termsServed >= 2` のフィルタを ingestion 時点で、または repository 層で適用
3. **demoRepository.ts** を **realRepository.ts** に置き換える
4. デプロイ後は定期バッチ（GitHub Actions等）でデータを更新

## 接続すべきデータソース（優先度順）

1. 国会会議録検索API (NDL) - 発言・質問データ
2. 衆議院 / 参議院 議員名鑑 - 議員基本情報
3. 政党マニフェストページ - 公約テキスト
4. 選挙公報データ - 候補者公約
5. 委員会所属データ - 委員会活動
6. 法案提出・賛否データ - 立法活動

## 注意事項

- 実在の議員データを扱う場合は、著作権・個人情報に注意すること
- 逐語引用は原典からの明確な引用として扱い、要約と区別すること
- データの鮮度・出典を必ず記録すること
